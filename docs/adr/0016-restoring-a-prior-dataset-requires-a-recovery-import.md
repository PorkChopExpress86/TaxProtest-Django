# Restoring a prior dataset requires a recovery import

Restoring a previously published county dataset requires an explicit recovery
import of retained sources through the normal validation, coverage review,
writer coordination, and audit process. Admin must not offer a simple old-snapshot
pointer toggle: dependent property or tax data may have changed since that
snapshot was published, so selecting it alone does not establish a consistent
restoration.

This records the chosen recovery contract, not a guarantee that all historical
sources remain available. Implementation of this contract is pending.
