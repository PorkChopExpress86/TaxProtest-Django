# Taxing units that levy no tax need no adopted rate

Tax impact requires an adopted rate for every applicable taxing unit (ADR-0012). County
jurisdiction rows also name units that levy no ad valorem tax: tax increment reinvestment
zones, whose increment is paid out of the participating units' own levies (Texas Tax Code
chapter 311); the appraisal district, which the units it serves fund (section 6.06); and a
BCAD refund entity. No source publishes a rate for them, so requiring one left every property
in such a unit permanently without tax impact: 135 Harris zone codes, and CAD, ZRFND and three
zones on Brazos accounts.

Each county owns an explicit list of its non-levying units and the reason shown for each.
Readiness excludes listed units from the rate requirement, and the report shows them with
that reason and no tax. A unit joins the list only on source evidence. An unlisted unit still
needs a rate, so a new zone or a renamed entity surfaces as a missing rate instead of being
assumed to levy nothing.

A published rate of zero means the rate has not been adopted yet. It is stored as no rate and
never marks a unit as non-levying.

Inferring non-levying units from names or from an absent rate was rejected: a levying unit
whose rate has not been imported would then price as zero tax.
