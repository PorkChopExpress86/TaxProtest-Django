# Brazos Partial publication is an explicit request

Brazos annual refresh remains strict: unavailable or failed year-matched GIS does
not automatically publish CAD-only data. An operator explicitly requests Partial
publication through the county-owned property-import operation and sees the
missing capabilities before applying. This preserves the meaning of an annual
request while permitting a deliberate, qualified Partial snapshot.

The current annual operation and CAD recovery modes support this distinction;
the complete operator presentation and qualification contract remain unverified.
